# Airborne Target Tracking via Kalman Filtering

State estimation and trajectory prediction of airborne targets under noisy measurement models using discrete Kalman Filtering.

## Methodology
* **Motion Model:** Constant Velocity (CV) 2D State-Space formulation
* **State Vector:** $[x, \dot{x}, y, \dot{y}]^T$
* **Numerical Technique:** Discrete-time matrix propagation and recursive covariance updates
